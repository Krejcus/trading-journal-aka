## Changes

- `Trade.autoConfluence` records the exact HTF/LTF capsules generated by replay. `backtestIntel` stamps new trades; dashboard, projected trade list, and full detail retain the field.
- Recalculation removes only previously recorded generated capsules. A manually added tag such as `u silné rezistence` or `odraz od mé zóny` survives. An existing manual capsule that equals new indicator output remains manual after subsequent recalculations. Legacy rows without provenance retain unknown tags rather than inferring ownership from their text.
- `reconcileBacktestConfluenceProvenance` lets the review dialog retain selected generated capsules and explicitly transfer a capsule to manual ownership.
- `storageService.updateTrade` requires a returned row ID before claiming success. Full review notes, custom tags, and provenance round-trip through all three reads.
- App Coach `search_history` and `find_similar_trades` use semantic results to select records, then replace stale embedded content and tag metadata with the currently loaded trade. Similarity search also excludes trades outside the selected live/backtest scope. Keyword retrieval still works if semantic transport fails.
- `get_recent_context` includes full trade notes and custom/HTF/LTF tags. The existing initial backtest prompt already contained these fields; its 500-trade cutoff now reports the omitted count and directs the model to retrieval.
