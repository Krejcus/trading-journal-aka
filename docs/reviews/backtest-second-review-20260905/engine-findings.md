## Intentional/model limitations rather than newly proved runtime bugs

- OHLC lacks within-bar order; conservative stop-first and explicit ambiguous outcomes are defensible. Limit-on-touch currently assumes complete fill with fixed slippage, not exchange queue/volume/bid–ask execution (`backtestEngine.ts:140–158,384–388`).
- Coverage currently proves successful fetched intervals, not that every tradable minute exists (`backtestCandleStore.ts:35–56`). Empty successful windows can be closures or missing source data; no exchange-calendar evidence is attached. No observed production-feed corruption claimed.
- Bootstrap uses realized exit rows as IID fixed-dollar observations (`Dashboard.tsx:606–610`, `backtestMonteCarlo.ts:27–29`). Partial exits remain separate observations; journal mapping drops positionId, and Lab dedupes only copier groupId/masterTradeId (`labAnalytics.ts:317–340`). This can inflate effective sample size and discard within-position/day loss clustering. It cannot establish whether a fitted strategy has a genuine out-of-sample edge.
- Parametric MonteCarloLab models independent binary wins/losses, not empirical tail distribution. Its “ruin” explicitly means configurable drawdown; dashboard ruin means account reaches zero. Distinguish definitions visibly.
- Main execution currently remains per run's fixed executionSymbol; markToMarket is not portfolio MTM. Do not claim simultaneous portfolio support based only on two chart instruments.

## Eight high-value development directions, each with an acceptance criterion

1. **One execution kernel for replay, unchanged-bracket comparison, alternative management, and batch experiments.** Same fills, gaps, cutoff, fees and ambiguity semantics. Acceptance: identical rules/input give identical event ledger and net P&L in every mode; long/short gap, cutoff, partial and same-bar fixtures all agree.
2. **Blind research mode with a data-visibility boundary.** Freeze future-dependent review/AI/notifications until cursor reaches the relevant horizon or user ends the blind trial. Acceptance: arbitrarily mutate every candle after cursor; chart, journal, AI context and visible statistics remain byte-equivalent until reveal.
3. **Data-quality manifest per experiment.** Record contract/source IDs, calendar, resolution, fetched coverage, missing tradable intervals, OHLC/tick validation and continuous-contract roll rules. Acceptance: a removed live-session minute makes affected results incomplete; declared weekend gaps do not; results reference an immutable data hash.
4. **Position lifecycle ledger and quantity-aware excursion/risk attribution.** Retain positionId through the journal, fills, scale-ins and partial exits; offer cash-ledger versus independent research-decision views. Acceptance: the two scale-in repros report $40 actual MFE and $0 actual MAE respectively; splitting one exit into ten slices does not create ten independent research samples.
5. **Selective intrabar validation.** Upgrade only ambiguous or execution-sensitive minutes to a finer available source, with explicit budget and provenance; use executable quotes where available. Acceptance: known tick sequence resolves both-sided touches correctly, missing detail retains bounds, no source invents a tick path from OHLC.
6. **Registered experiment / out-of-sample workflow.** Freeze rules/version before untouched holdout, chronological train/validation/test, walk-forward and embargo appropriate to overlapping labels. Acceptance: every explored variant is counted, holdout cannot silently enter optimization, and every result can be traced to rules fixed before evaluation.
7. **Risk lab with seed, block bootstrap and cost stress.** Resample positions/days or regimes, expose IID as assumption; separate fixed-dollar/fractional sizing, account insolvency and prop drawdown thresholds. Acceptance: same seed reproduces output; partial slicing leaves position-based sample unchanged; fees lower net expectancy; no negative risk after exhaustion.
8. **Reproducible evidence package and sensitivity report.** Save data hash, engine/version hash, ledger, assumptions, seeds and ambiguity bands; compare optimistic/conservative/finer-data results. Acceptance: a clean runner replays the package to identical economics, confidence intervals disclose independent sample count and all excluded/missing data.
