not enough: each row names the strongest evidence currently available and the
remaining external gate. The shared React product remains the source of truth;

## Release gates that are intentionally not bypassed

- The prior build physically showed real Home Screen values. Do not claim the
  new manual/WidgetKit-push closed-app refresh or durable trade/equity ledger
  physically complete until the current build is installed, both refresh paths
  are observed server-side, and a naturally closed trade is observed.
- General APNs, ARM/DISARM and the remote Live Activity end path are physically
  proven. Do not claim changing remote P&L until a naturally active position has
  been observed on the Lock Screen; never manufacture a broker position for a test.
- Do not deploy Vercel/Supabase changes or change production secrets as part of
  an iPhone smoke test without explicit approval.
- Dictation, notification notes, and widget quick actions only prepare or
  navigate. They never create a trade without the user's explicit Save action.
